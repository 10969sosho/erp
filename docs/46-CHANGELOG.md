# Changelog

## Versioning

This document records changes to the specification. Use date, version, change type, affected documents, reason, impact, migration, and approver. Breaking behavior requires major version; additive contract minor; typo/clarification patch.

## Change Process

Proposal -> impact analysis -> business/architecture/security review -> update affected docs and IDs -> test/traceability review -> approval -> publish. Never silently change a business rule.
