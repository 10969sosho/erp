# Glossary

| Term | Definition |
|---|---|
| AR | Accounts Receivable / piutang |
| AP | Accounts Payable / hutang |
| COA | Chart of Accounts |
| COGS | Cost of Goods Sold / HPP |
| FEFO | First Expired, First Out |
| FIFO | First In, First Out |
| GRNI | Goods Received Not Invoiced |
| Lot/Batch | Kelompok produk dengan identitas produksi/expiry |
| Posting | Membentuk dampak resmi pada subledger/GL/stock |
| Reversal | Jurnal/movement lawan untuk membatalkan posting |
| SoD | Segregation of Duties |
| Stock Card | Riwayat pergerakan dan saldo stok |
| Three-way match | PO, receipt, supplier invoice |
| UOM | Unit of Measure |
| O2C | Order to Cash |
| P2P | Procure to Pay |
| RPO/RTO | Recovery Point/Time Objective |
| Extension | Kode/data tambahan tanpa mengubah core |
