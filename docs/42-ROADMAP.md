# Roadmap

## Phase 0: Foundation

Tenant/company/branch/warehouse, identity/RBAC, master data, numbering, settings, audit, document/attachment, API skeleton.

## Phase 1: Transaction Core

Purchasing PR-RFQ-quotation-comparison-PO-receive-QC, sales lead/customer-quotation-SO-delivery-invoice, stock ledger, basic AR/AP/cash, approval.

## Phase 2: Control and Insight

Costing, lot/serial/expiry, warehouse scan, bank reconciliation, tax, budgets, assets, closing, reports, dashboards, imports/exports.

## Phase 3: Scale and Ecosystem

CRM/service/project depth, supplier/customer portals, event integration, scheduled automation, BI, advanced forecasting, extension marketplace.

Each phase requires acceptance, migration, performance, security, and operational readiness; roadmap does not override functional contracts.
