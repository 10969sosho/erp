# Dashboard

## Layers

Operational dashboards show queues/exceptions; management dashboards show drivers/trends; executive dashboards show outcome/health. Each card has metric ID, formula, source, as-of timestamp, scope, currency, drilldown, and target.

## Baseline Cards

Revenue, gross margin, cash position, AR/AP aging, DSO/DPO, open PO/SO, fill rate, stock value, turnover, expiry risk, low stock, purchase price variance, supplier OTIF, sales conversion, return rate, and approval backlog.

## UX and Security

Use responsive cards, visible stale-data indicator, filter by company/branch/warehouse/period, and drilldown to permission-aware records. No dashboard can bypass record-level access.
