# Settings

## Hierarchy

System defaults < tenant < company < branch < warehouse < user preference. More specific setting overrides only allowed keys. Effective setting must be inspectable with source and version.

## Setting Groups

Localization, fiscal calendar, numbering, tax, currency/rate, UOM, costing, stock negative/expiry, pricing/discount, credit, payment terms, approval, notification, document/retention, security, integration, report, and feature flags.

## Controls

Sensitive settings require admin permission and approval; effective-dated changes; validation on publish; no secret stored in general settings; audit before/after; test mode for integrations; rollback to prior version.
