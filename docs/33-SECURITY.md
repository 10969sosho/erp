# Security

## Controls

OIDC/OAuth2, MFA, passwordless/strong password policy, RBAC plus scope and field security, least privilege, SoD, session expiry, device/IP controls where required, encryption in transit/at rest, secret manager, secure headers, CSRF protection, input/output validation, rate limits, and dependency scanning.

## Data Protection

Classify public, internal, confidential, restricted. Mask bank, tax identity, margin, and personal data. Support data retention, legal hold, subject access/deletion only where legally allowed, tenant isolation tests, and secure file scanning.

## Operations

Security incidents have severity, owner, containment, evidence, notification, remediation, and postmortem. Run access review, vulnerability scan, penetration test, backup restore test, and disaster exercise on schedule defined in `39-NONFUNCTIONAL.md`.
