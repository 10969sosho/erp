# Modules

## Module Catalogue

| Module | Core capability | Primary entities |
|---|---|---|
| Platform | Tenant and organizational scope | tenant, company, branch, warehouse, setting |
| Master Data | Reusable reference data | item, party, UOM, price, tax, currency |
| Purchasing | Procure-to-pay | PR, RFQ, quotation, PO, receipt, QC, invoice |
| Sales | Order-to-cash | lead, customer, quotation, SO, delivery, invoice |
| Inventory | Quantity/value control | stock movement, lot, serial, count, adjustment |
| Warehouse | Physical operations | zone, bin, wave, pick, pack, dispatch |
| Finance | Cash and settlement | payment, receipt, bank, reconciliation |
| Accounting | Double-entry reporting | account, journal, ledger, period, budget, asset |
| Tax | Tax determination/evidence | tax code, tax transaction, filing period |
| CRM | Relationship lifecycle | lead, opportunity, activity, campaign |
| Project | Work and cost tracking | project, task, timesheet, cost |
| Service | Post-sale support | ticket, SLA, case activity, resolution |
| Control | Governance | workflow, approval, notification, audit |
| Platform Integration | External exchange | API client, webhook, import job, integration log |

## Mandatory Module Contract

Untuk setiap module: tujuan, business problem, flow, actor, use case, requirement, entity, database, relationship, validation, workflow, approval, notification, permission, audit trail, API, UI, UX, report, dashboard, future improvement, dan best practice wajib dijelaskan. Domain detail ada pada `21`-`28`; kontrak lintas module ada pada `06`, `11`, `17`, `18`, `19`, `32`, dan `33`.
