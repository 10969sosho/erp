# Pages

## Page Registry

| Page | Purpose | Main layout/data | Actions |
|---|---|---|---|
| Dashboard | KPI and exception | Cards, chart, drilldown | Filter, export |
| Master list/detail | Maintain reference | Table + form | Create, edit, archive |
| PR/RFQ/PO | Procurement | Header, lines, approval timeline | Submit, approve, convert |
| Receipt/QC | Receive stock | Scan lines, QC panel | Receive, reject, post |
| SO/Delivery | Fulfill sales | Availability, picking, delivery | Allocate, pick, dispatch |
| Invoice/Payment | Settlement | Totals, tax, allocations | Post, pay, reconcile |
| Stock ledger | Trace stock | Movement table + balance | Filter, export |
| Journal/ledger | Accounting | Lines, dimensions, drilldown | Post, reverse |
| Approval inbox | Decisions | Queue + evidence drawer | Approve, reject, reassign |
| Report builder | Analysis | Filter, columns, pivot | Save, export, print |
| Workflow/settings | Configure policy | Versioned forms | Publish, deactivate |
| Audit/integration | Operations control | Event/log table | Inspect, retry |

## Mandatory Page Specification

Setiap page harus mendokumentasikan Purpose, Layout, Card, Table, Filter, Action, Button, Permission, API, dan Validation. Detail standar form, permission, API, dan validation dirujuk dari `16-FORM-STANDARDS.md`, `06-PERMISSION.md`, `18-API-STANDARD.md`, `17-VALIDATION.md`.
